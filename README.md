# MacIsland V0.3

原生 macOS 灵动岛基础框架，使用 Swift、SwiftUI、AppKit 和 Apple 公开 API，无第三方依赖。最低 macOS 14.0。

## 打开与运行

打开 `MacIsland.xcodeproj`，选择 MacIsland scheme 和 My Mac，运行即可。
应用不显示 Dock 图标；菜单栏的胶囊图标提供设置、显示、隐藏和退出。

设置窗口可选择自动、主显示器或指定显示器，调整悬停等待时间（0.10–0.80 秒），开关悬停展开和弹性动画。显示状态与偏好会保存到本机，下次启动恢复。关闭悬停展开时整个灵动岛窗口支持鼠标穿透。
默认 Idle 完全透明，不显示额外黑块。鼠标移到刘海或其下沿 2 点的透明感应区时，依次进入 Compact 和 Expanded，移开后收起并隐藏。无刘海屏幕使用顶部中央 132 × 4 点的透明触发区；触发区不拦截鼠标点击。
展开后提供三个窗口操作：左半屏、铺满屏幕、右半屏。不包含“收进”功能，也没有音乐或电池模块。

## 窗口控制

首次使用时，点击灵动岛的“开启窗口控制”或菜单栏“窗口控制授权…”，在系统设置 → 隐私与安全性 → 辅助功能中允许 MacIsland。授权由用户手动完成；返回目标应用后重新悬停即可刷新权限状态。

- 左半屏 / 右半屏：调整当前应用聚焦窗口，使用窗口所在屏幕的可用区域。
- 铺满屏幕：保留菜单栏和 Dock 的可用区域最大化，不进入 macOS 独立全屏 Space。
- 跳过最小化、非标准窗口、不可调整大小窗口；覆盖整个显示器的窗口按全屏保护处理。
- 应用有最小尺寸或不支持调整时提示未完整完成，不会把失败当成成功。
- 当前应用在点击前切换时要求再次确认目标；面板不激活、不抢走目标应用焦点。

实现使用公开的 ApplicationServices Accessibility API ，无需屏幕录制权限。窗口操作在独立串行队列执行，设置消息超时，避免阻塞灵动岛动画。窗口标题与内容不保存、不上传。

命令行构建（不更改系统 xcode-select）：

```sh
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer xcodebuild \
  -project MacIsland.xcodeproj -scheme MacIsland \
  -configuration Release -derivedDataPath build build
```

本地运行产物位于 `build/Build/Products/Release/MacIsland.app`。采用本机 ad-hoc 签名，未公证；面向他人分发时需自行配置 Developer ID。

## 模块

- App：生命周期、菜单栏入口。
- Settings：原生设置界面、本地偏好保存。
- Screen：显示器 UUID 标识、选择与断开回退；由 NSScreen.frame、safeAreaInsets、auxiliaryTopLeftArea / auxiliaryTopRightArea 计算刘海尺寸与窗口位置。
- Window：透明、无边框、非激活 NSPanel；鼠标命中、状态切换、防抖、睡眠恢复与显示器变更处理。
- Island：三态模型、SwiftUI 内容、spring 动画和共享轮廓。
- WindowActions：窗口动作、坐标转换与分屏计算、辅助功能适配器、工具栏与授权状态。

自动模式优先选择有刘海的显示器；没有刘海时选择主屏幕。主显示器模式使用系统屏幕列表首项，不随当前应用焦点变化。指定显示器通过公开 API 的 UUID 保存；断开后回退到自动模式，重新连接后恢复原选择。合盖或断开显示器后重新选择，支持负坐标显示器布局。本版本只显示一个灵动岛。刘海屏的文字避开摄像头区域；普通屏顶部居中，仅展开时显示黑色界面，默认不占用菜单栏视觉空间。

位置和刘海尺寸来自系统；各状态的内容宽度、间距与圆角是可调整的设计参数。

透明区域及圆角外侧通过 NSPanel.ignoresMouseEvents 穿透。SwiftUI 每帧报告实际动画尺寸供命中检测使用；可见时以 30 Hz 检测系统指针（切换延迟最高约一个采样周期），隐藏或睡眠时停止。基础悬停无需授权；控制其他应用窗口需辅助功能权限，无需输入监控或屏幕录制权限。尊重系统“减少动态效果”。

## 验证

执行 `./Tests/run-checks.sh`，覆盖：

- 窗口动作模拟适配器检查：坐标转换、奇数宽度分屏、固定/全屏窗口保护、尺寸限制反馈。
- 刘海尺寸、无刘海显示器、负坐标布局、缺失区域信息回退。
- 三种状态的大小顺序与透明圆角命中。
- 注入指针位置验证 Idle → Compact → Expanded → Idle。
- 动画最终尺寸与鼠标命中尺寸一致、鼠标穿透切换。
- 展开期间隐藏、取消待执行切换、再次显示。
- 显示器选择、主屏策略、断开回退与空屏幕列表。
- 设置保存恢复、异常等待时间限制、禁用悬停与关闭动画。
- 快速离开后重新进入保持展开、隐藏时修改设置、睡眠唤醒时保持可见性。

已通过 Xcode 27.0 的 Debug / Release 构建和上述检查，并启动检查内置刘海屏窗口、设置窗口布局及显示器选择。
UI 自动化指针不改变 NSEvent.mouseLocation，故真实鼠标交互仍需人工验收。窗口动作已使用模拟适配器验证，工具栏已渲染检查；尚未在用户授权后控制其他应用实测。外接屏、热插拔、全屏 Space、睡眠唤醒也需相应设备/场景实测；几何和模拟适配器测试不代替实机验证。

设置变更会重置灵动岛到 Idle；显示器切换、隐藏和睡眠都会取消未完成的展开任务。

建议手动验收：缓慢移入刘海下缘与移出、快速反复进出、点击透明边角后的下层应用、菜单显示/隐藏/退出、切换 Space、插拔外接显示器。
