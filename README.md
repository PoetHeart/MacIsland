# MacIsland

**拖到顶部整理窗口，一个菜单栏图标查看电量、Wi‑Fi 和音量。**

MacIsland 是一款免费的开源 **Mac 便捷工具**，把 **灵动岛（Dynamic Island）窗口管理** 和 **三合一状态栏** 放在一起。拖动窗口到屏幕顶部，就能分屏或居中，松手前可预览位置，再点一次恢复原状；右上角的图标实时显示电量、Wi‑Fi 和输出音量。灵动岛平时隐藏，需要时移到刘海或顶部中央就能用，也支持没有刘海的外接显示器。

## 你可以做什么

- **三合一菜单栏图标**：一个图标显示实时电量、Wi‑Fi 和输出音量，点击查看详细状态及应用菜单，自动适配浅色和深色菜单栏。
- **拖动就能分屏**：按住窗口标题栏拖到顶部，移到左半屏、居中或右半屏按钮上，松手应用。移到操作区外松手，或按 Esc 取消。
- **拖动位置预览**：拖到布局按钮时显示半透明目标区域，居中预览跟随设置比例；移出或取消即隐藏。
- **再点一次还原**：对同一窗口再次点击刚用过的布局，恢复调整前的位置和大小。手动移动或缩放窗口后，会以新位置作为下一次恢复起点。
- **左半屏、铺满屏幕、居中、右半屏**：快速整理当前应用窗口，不抢走目标应用焦点。
- **可调居中大小**：默认宽、高各为屏幕可用区域的 60%，可在 30%–100% 之间调整并保存。
- **不凸出的灵动岛**：默认完全透明，移入刘海或屏幕顶部中央展开，移开后连续收起。
- **适配多显示器**：自动优先刘海屏，也可指定显示器；断开后回退，重连后恢复。
- **中英文切换**：在设置的 Language / 语言 中选择简体中文或 English，即时生效并保存。
- **更自然的动画**：可中断弹簧、稳定的按钮布局和独立淡入淡出；遵循系统“减少动态效果”。

Swift + SwiftUI + AppKit，公开 Apple API，无第三方依赖。

## 看懂菜单栏图标

- **外圈弧线**：剩余电量；闪电表示正在充电，插头表示已接电源。
- **中间 Wi‑Fi**：连接和信号强度；斜线表示 Wi‑Fi 已关闭。
- **底部圆点**：默认输出设备的音量，亮点越多音量越大；叉号表示静音。

点击图标可查看电量百分比、Wi‑Fi 状态和音量百分比。图标样式参考 [Status Trio](https://github.com/lingyired/status-trio) / iPhone Duo。

## 下载与安装

1. 下载 [MacIsland-0.6.0-universal.dmg](https://github.com/PoetHeart/MacIsland/releases/download/v0.6.0/MacIsland-0.6.0-universal.dmg)。
2. 打开 DMG，将 **MacIsland.app** 拖到 **Applications**。
3. 从“应用程序”启动 MacIsland。菜单栏图标提供设置、显示、隐藏和退出。
4. 要控制其他应用窗口，点击“窗口控制授权…”，在系统设置的“隐私与安全性 → 辅助功能”中手动允许 MacIsland。

**升级：** 先从菜单栏退出旧版，再将新版拖入 Applications 替换，最后重新启动。

**系统要求：macOS 14.0 或更新。** DMG 包含 Apple Silicon / Intel 通用应用；本次在 Apple Silicon 上完成运行检查，Intel 仅完成编译检查。

**签名说明：** 当前为 ad-hoc 签名，尚未使用 Developer ID 签名或经过 Apple 公证，下载后可能被 Gatekeeper 阻止。请在安装前了解此限制；也可使用 Xcode 从源码构建。发布页提供 SHA-256 校验文件。

## 使用说明

选择目标应用窗口，然后把鼠标移到刘海或屏幕顶部中央。无刘海屏幕的触发区为顶部中央约 132 × 4 点；透明区不拦截点击。

“铺满屏幕”使用菜单栏和 Dock 之外的可用区域，不进入独立全屏 Space。窗口的最小尺寸、全屏状态及应用自身限制可能阻止调整；界面会反馈失败。基础悬停无需权限，窗口控制仅需辅助功能权限，不需要录屏权限。

拖动与恢复同样需要辅助功能权限，并要求启用悬停。只有标题栏附近开始、窗口位置随鼠标实际移动且大小不变的拖动才会激活；不同应用的自定义标题栏可能不支持。拖动操作区保持鼠标穿透，不接管原窗口的鼠标释放事件。恢复记录按窗口保存在本次运行内（最多 32 个窗口），重启后清空；原屏幕断开时将恢复窗口限制在可用屏幕内。

菜单栏状态仅在本机读取，使用 Apple 公开的 IOKit、CoreWLAN 和 CoreAudio API；不读取 Wi‑Fi 名称，不要求定位、麦克风或录屏权限。音量指默认输出设备，不采集声音。无内置电池或不支持读取音量的设备会明确标示；Wi‑Fi 连接不等于已验证互联网可用。

## 开发与验证

打开 `MacIsland.xcodeproj` 即可开发，运行 `./Tests/run-checks.sh` 执行回归检查。执行 `./scripts/release-dmg.sh` 构建通用应用并生成 DMG 与校验文件。

测试覆盖分屏和居中坐标、多屏回退、设置持久化、中英文、透明触发区、最上沿触发及反复打断动画。第三方窗口操作使用模拟适配器验证；不同应用、显示器热插拔及 Intel 实机表现仍需实测。

更多架构与测试说明见 [开发文档](docs/DEVELOPMENT.md)。
